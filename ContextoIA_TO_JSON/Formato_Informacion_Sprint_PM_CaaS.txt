QUÉ GENERARÁ COPILOT A PARTIR DE ESTE ARCHIVO
============================================================

No es necesario completar manualmente los siguientes datos:

- Clasificación: Valor Técnico / Avance Relevante / Valor Funcional.
- Porcentaje de avance de cada HA/HU.
- Avance ponderado del Sprint.
- Valor generado.
- Próximo paso ejecutivo.
- Consolidación de riesgos y dependencias.
- Estructura JSON final para la automatización.

Copilot utilizará:

Tareas completadas / tareas totales
        ↓
Porcentaje de avance HA/HU
        +
Story Points
        ↓
Avance ponderado del Sprint

Además, contrastará:

Descripción
+ Criterios de aceptación
+ Contexto real de avance
+ Dependencias / bloqueos
+ Observaciones
        ↓
Clasificación + Valor generado + Próximo paso
