============================================================
CONTEXTO MANUAL DEL SPRINT - CaaS TESORERÍA
============================================================

OBJETIVO
Registrar únicamente información del Sprint que NO esté disponible o
no pueda interpretarse correctamente desde metricas_celula.json.

Este archivo complementa las métricas de Azure DevOps. No reemplaza el
JSON operativo y no debe repetir información que ya venga allí.

NO COPIAR AQUÍ:
- Nombre o descripción de la HU/HA.
- Épica / proyecto.
- Célula.
- Story Points.
- Estado de Azure DevOps.
- Criterios de aceptación.
- Tareas ni porcentaje de avance.

Copilot cruzará este archivo con metricas_celula.json para construir
Contexto_HAs_JSON.json y posteriormente el informe semanal.

REGLAS RÁPIDAS
- Registrar solamente hechos reales y vigentes del Sprint.
- Para relacionar información con una HU/HA basta con indicar su ID.
- No es obligatorio diligenciar todas las secciones.
- Si una sección no aplica, dejarla vacía o escribir NINGUNA.
- No inventar responsables ni fechas. Si no están definidos, dejarlos vacíos.
- Una dependencia no es automáticamente un bloqueo.
- Un riesgo no significa que el problema ya ocurrió.
- Un bloqueo debe indicar algo que realmente impide continuar.

============================================================
QUÉ GENERARÁ COPILOT A PARTIR DE ESTE ARCHIVO
============================================================

Copilot cruzará este contexto manual con metricas_celula.json para:

- Conservar ID, nombre, épica, célula, Story Points y estado desde Azure.
- Calcular el avance según las reglas vigentes.
- Clasificar Valor Técnico / Avance Relevante / Valor Funcional.
- Construir valor generado y próximo paso con evidencia.
- Identificar desviaciones y acciones de recuperación.
- Proponer semáforo cuando exista evidencia suficiente.
- Consolidar dependencias, bloqueos y riesgos.
- Construir novedades ejecutivas.
- Preparar hitos y compromisos informados.
- Construir el resumen ejecutivo y "Lo más importante".
- Generar Contexto_HAs_JSON.json para alimentar el programa del PDF.

IMPORTANTE:
Copilot no completará responsables, fechas, impactos, decisiones o
compromisos que no hayan sido informados o respaldados por evidencia.
